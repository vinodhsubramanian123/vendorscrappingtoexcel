# Pipeline Data Dictionary & AI Memory Structures

This dictionary is the **single source of truth** for all JSON schemas and data structures generated and consumed by the HPE OCA Catalog Intelligence pipeline. AI Agents MUST reference this document to understand the shape of the data they are interacting with to prevent token waste from reading source code.
